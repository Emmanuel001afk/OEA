# Life in Words — illustrated quote themes

Eleven AI-generated cinematic quote artworks are bundled as real density-independent WebP resources, not procedural placeholder gradients. Eight new scenes extend the three user-selected designs. The collection is featured first in Themes, with the original themes retained below it.

| Theme | Scene | Palette |
|---|---|---|
| Borrowed Light | Hourglass and twilight sea | Amber / charcoal |
| Quiet Growth | Ancient forest steps | Jade / green |
| Tide & Release | Moonlit shore | Indigo / silver blue |
| After the Storm | Lighthouse and breaking clouds | Slate / warm gold |
| Roots & Wings | Cliffside tree and birds | Moss / antique gold |
| Unfinished Story | Journal, butterflies and stars | Violet / midnight |
| Slow Becoming | Stepping stones on a misty lake | Teal / blush |
| Precious Ordinary | Autumn path and an older couple | Copper / brown |
| Choose Peace | Rowboat and lantern on a lake | Jade / cream |
| The Light You Carry | Lantern on a snowy mountain path | Navy / amber |
| Open Horizon | Coastal doorway at dawn | Ocean blue / coral |

Each is a complete theme: shared Home/lock artwork, distinct coordinated light/dark accents, panel tint, icon shape, glass dock and fade motion. Artwork is available separately in the wallpaper library and through the existing theme preview, export/import and wallpaper application paths. Applying one never moves or removes the user's apps or widgets, and none is applied automatically.

The eleven images total roughly 3.5 MiB. Original PNGs and unselected candidates are not shipped. `quote-theme-gallery.html` shows the exact bundled artwork. Text was reviewed visually; these are original short messages with no attributed authorship. Generated image typography is baked into the artwork (English), not dynamic/localized UI text.

Validation: static checks, resource/image inspection, and catalog regression tests for all eleven real artwork references, shared Home/lock images, unique IDs and known styles. Final Android build and test status is recorded on the PR. Device checks should cover preview loading, screen aspect cropping, launcher icon readability, lock clock overlap and Home/Lock/Both application. Android or OEM wallpaper cropping and lock-screen widgets can still obscure words; preview the selected target before applying.
